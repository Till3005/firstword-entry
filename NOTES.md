# NOTES

This entry answers the make.fun bounty `u-0xkianno-one-word-first-thought-106abaf8`, which asks for a program whose stdout is a one-word first thought.
Our answer is `Undo.` — the instinctive one-word reaction to wishing something could be taken back.
Running `node main.ts` emits exactly that line plus a trailing newline, nothing else.
